# 《汴京漫游》优化计划与发布路线

> 定位：让"可玩、可体验、可分享"的作品达到公众号/小红书/知乎发布水准。
> 优先级：P0（决定能否玩起来）→ P1（高性价比体验）→ P2（内容深度）→ P3（发布与传播）。

## P0 — 必须（决定"能不能玩起来"）

| # | 任务 | 现状 | 方案 | 验收 |
|---|---|---|---|---|
| P0-1 | **任务指引/方向箭头** | ✅ 已完成 | 小地图金色目标点 + 屏幕边缘方向箭头 + 距离标签「☛ 桥头干粮 · 38m」；无进行中任务时指向首个可接任务人 | 接任务后 3 秒内知道去哪 |
| P0-2 | **开场引导** | ✅ 已完成 | 2 句剧情开场（进京赶考书生）+ 操作一屏一讲（含触屏版）+ 记忆跳过一次；引导结束后自动指向货郎 | 新玩家 1 分钟内上手 |
| P0-3 | **暂停/设置菜单** | ✅ 已完成 | Esc/触屏「菜单」按钮打开：继续/音量滑块(记忆)/重新开始/返回标题 | 可随时暂停并调音量 |
| P0-4 | **WebGL 兼容提示** | 待做 | 检测 WebGL 失败显示友好提示页 | 低端机不白屏 |
| P0-5 | **加载进度** | 待做 | 水墨风加载动画（进度条） | 无白屏等待 |

## P1 — 高性价比体验提升

| # | 任务 | 方案 | 验收 |
|---|---|---|---|
| P1-1 | **成就卡/分享图** | ✅ 已完成 | 全任务完成弹「画卷集齐」卡片（Canvas 生成：实拍帧+印章+统计，PNG 可保存/长按分享） | 可一键分享到朋友圈/小红书 |
| P1-2 | **沉浸氛围** | 环境音（水流/鸟鸣/市井嘈杂）+ 脚步随地面变化 + 傍晚暖光 | 听觉上"活"的汴京 |
| P1-3 | **移动端再优化** | 横竖屏适配、摇杆/按钮防误触、2x 像素比帧率压测 | 主流机型 ≥30fps 且清晰 |
| P1-4 | **音效细化** | 开门吱呀/翻页/铜钱/盖章/成交等交互音 | 交互反馈更丰富 |
| P1-5 | **桌面描边可选** | 设置里可开关墨线描边（性能/风格偏好） | 用户可控画风 |

## P2 — 内容深度（留人）

| # | 任务 | 说明 |
|---|---|---|
| P2-1 | 更多小玩法 | 听书点唱、夜市猜灯谜、河上撑船竞速（扩展现有节奏玩法） |
| P2-2 | NPC 作息 | 白天出摊、入夜收摊关门、"活"的汴京 |
| P2-3 | 收集要素 | 各景点打卡（虹桥/城门/酒肆/码头…）集齐拼成完整画卷 |
| P2-4 | 任务扩展 | 从 8 条扩到 12~15 条，含连串剧情任务 |
| P2-5 | 昼夜/天气 | 黄昏/夜晚氛围切换，水面光斑变化 |

## P3 — 发布与传播

| # | 任务 | 说明 |
|---|---|---|
| P3-1 | 分享元信息 | `<title>/<description>/og:image` 缩略图（微信/QQ 分享显示） |
| P3-2 | 宣传素材 | 30s 竖屏视频（小红书）+ 横屏演示（公众号）+ 程序化生成技术文（知乎） |
| P3-3 | 微信内置浏览器实测 | X5/WKWebView 兼容性与音频自动播放 |
| P3-4 | 体验优化漏斗 | 首任务完成率 / 停留时长埋点（轻量，不侵入） |

## 建议执行顺序

```
第一批（已完成 ✅）：
  P0-1 任务指引 → P0-2 开场引导 → P0-3 暂停/音量 → P1-1 成就分享卡
第二批（待做）：
  P0-4 兼容提示 → P0-5 加载进度 → P1-2 沉浸氛围 → P1-3 移动端压测 → P1-4 音效细化
第三批（发布）：
  P3-1 分享元信息 → P3-2 宣传素材 → P3-3 真机实测
内容扩展（按传播反馈决定）：P2 各条
```

## 发布验收清单（Go/No-Go）

- [ ] 移动端主流机型（iOS/Android）进图流畅、清晰、无白屏
- [ ] 首次进入 2 分钟内能接到并完成一个任务
- [ ] 全 8 任务可完成、无卡死/崩溃
- [ ] 微信/QQ 打开链接可分享且显示标题缩略图
- [ ] 成就分享卡生成正常
- [ ] 无外部网络请求（离线可玩）
