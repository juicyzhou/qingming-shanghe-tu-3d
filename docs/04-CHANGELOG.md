## 经验教训（后续开发必读）

1. **真实 GPU 与 swiftshader 渲染有差异**：部分伪影仅真机出现，务必用"用户截图分析 + 真机调试工具（射线检测）"定位，勿只依赖本地无头测试。
2. **方向/坐标约定要一次定死并写注释**：右向量应为 `F×U`，曾因推导错误两度返工。
3. **后处理（composer）的 canvas 读回在 swiftshader 不可靠**：会产生假"灰蓝/反光"，需用 Chrome 原生截图或探针交叉验证。
4. **第一人称看不到自己的角色** 是行业默认，否则身体会挡视线（本次最大"幽灵"即此）。
5. **透明度正确实现**：ShaderMaterial 需手动处理 alpha，否则透明通道深度排序会闪烁/消失。
