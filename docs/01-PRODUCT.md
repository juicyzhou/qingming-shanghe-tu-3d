# 《汴京漫游 · 3D 清明上河图》产品方案设计

> 版本：v1.0 ｜ 更新：2026-08 ｜ 状态：核心玩法完成，面向发布打磨中
> 线上体验：https://juicyzhou.github.io/qingming-shanghe-tu-3d/

## 一、产品定位

**一句话**：以北宋《清明上河图》为蓝本的**纯程序化生成** 3D 沉浸式古风街市漫游小游戏——零外部资源、浏览器即玩、可直接分享。

**核心卖点**：
1. **画卷即世界**：虹桥、汴河、沿街店铺、城门、集市、50 余位宋代人物全部由代码实时生成，无任何模型/贴图/音频文件（全部 Canvas / Web Audio 程序化绘制）。
2. **进得去的画**：店铺真实可进，每店有专属内室陈设与掌柜；任务、对话、经济、小玩法构成完整游戏闭环。
3. **国画手绘风**：米色纸感、墨线描边、暖色 toon 光影、雾霭层次，还原水墨意境而非写实 3D。
4. **零门槛传播**：GitHub Pages 一键托管，手机/电脑浏览器即玩，适合公众号/小红书/知乎分享。

**目标用户**：历史文化爱好者、国风美学受众、轻量游戏玩家、Web 技术从业者。

## 二、玩法设计

### 2.1 核心循环
```
进入画卷 → 自由探索街市 → 发现任务人物(头顶?) → 接任务
→ 跑腿/采买/寻人/小玩法 → 交付 → 获得铜钱与声望 → 达成画卷成就
```

### 2.2 玩法系统
| 系统 | 说明 |
|---|---|
| 探索 | WASD/虚拟摇杆移动、Shift 疾跑、双视角（V 切换第一/第三人称）、可进出店铺 |
| 交谈 | 靠近 NPC 按 E，羊皮纸对话面板，分支选项 |
| 任务 | 8 条任务线，跨场景联动，可同时进行 |
| 经济 | 铜钱货币，可购买茶叶等任务物品，背包管理 |
| 小玩法 | 节奏撑船（空格/点按 5 桨），招客计数等 |
| 结算 | 任务完成弹结算面板（奖励明细），全局声望与成就 |
| 小地图 | 右上角实时显示城镇、店铺、NPC 与玩家位置 |

### 2.3 任务线一览
| # | 任务 | 类型 | 奖励 |
|---|---|---|---|
| 1 | 桥头干粮 | 送物 | 30 文 + 烧饼 |
| 2 | 茶肆茶叶 | 购买+送 | 20 文 |
| 3 | 寻访说书人 | 寻人 | 40 文 |
| 4 | 大夫的药草 | 采集 | 25 文 |
| 5 | 撑船过桥 | 节奏小玩法 | 50 文 |
| 6 | 城门传话 | 传话 | 35 文 + 公文 |
| 7 | 码头送布 | 取物+送 | 40 文 |
| 8 | 糖人招客 | 招揽计数 | 30 文 |

### 2.4 内容规模
- **场景**：约 400×300 单位；主街、虹桥、汴河、城门、集市、码头、南北河岸
- **店铺**：10 家可进入（酒楼/茶肆/客栈/药铺/布庄/香铺/杂货/点心/肉铺/米铺），各配掌柜与专属陈设
- **NPC**：48 位（含 10 位店内掌柜），20+ 职业
- **摊位**：10 处集市摊位

## 三、艺术风格

- **渲染**：自定义 toon 着色器（3 段量化明暗 + 暖色环境光 + 克制边缘光 + 柔和高光压缩），米色纸感背景与雾
- **后处理**：墨线描边（桌面）、暖色校色、暗角、纸面噪点
- **程序化贴图**：木板/石板/土/草/瓦/白墙/门窗/布幌/水墨卷轴/人脸等 Canvas 绘制
- **人物**：宋代服饰 + 程序化随机外观（肤色/身高/发型/胡须/帽子/衣色），保证千面辨识

## 四、平台与分发

- **Web（GitHub Pages）**：https://juicyzhou.github.io/qingming-shanghe-tu-3d/
- 桌面端（Chrome/Edge/Firefox）+ 移动端（触屏摇杆自动适配，横屏更佳）
- 计划：公众号（H5 链接）、小红书（成就卡/截图/视频）、知乎（技术文章）

## 五、商业化（非目标）

当前定位为**体验型/传播型作品**，无付费点。长期可考虑：命题卷轴 DLC、定制店铺冠名、企业文化授权等（均为非必须）。

## 六、关键体验指标（发布验收）

| 指标 | 目标 |
|---|---|
| 首次进店引导完成率 | ≥ 60% |
| 完成首条任务时间 | ≤ 2 分钟 |
| 移动端帧率（主流机型） | ≥ 30fps |
| 全任务完成率 | ≥ 30% |
| 移动端画面清晰度 | 2x 像素比渲染 |
