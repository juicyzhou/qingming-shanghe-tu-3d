# 《汴京漫游》资产总结（全部程序化生成）

> 零外部资源文件：无模型、无贴图、无音频、无字体。所有内容由代码在运行时生成。

## 一、资产总览

| 类别 | 生成方式 | 数量/规模 |
|---|---|---|
| 3D 网格 | 基本几何体（Box/Cylinder/Sphere/Cone/Plane）+ 自定义分段曲面 | 场景 ~2,200 对象，可见 ~812 draw call |
| 贴图 | **Canvas 2D 绘制** → CanvasTexture | 12 类 |
| 人物 | 参数化木偶角色（身体部件 + 枢轴动画） | 50 位（46 街人 + 2 夜巡 + 玩家） |
| 音频 | **Web Audio** 振荡器合成 | 5 类（BGM + 4 音效） |
| UI | 原生 DOM/CSS + Canvas 小地图 | 全部 |

| `dirtTexture` | 沙土斑点 | 地形底 |
| `grassTexture` | 草叶簇 | 河岸草带 |
| `woodTexture` | 木板 + 木纹 | 建筑/桥/家具 |
| `wallTexture` | 白墙 + 斑驳 | 建筑墙体 |
| `roofTexture` | 瓦片弧行 | 屋面 |
| `bannerTexture` | 竖长店幌 + 汉字（酒/茶/药…） | 店铺幌子 |

## 三、几何资产

### 3.1 建筑（10 家店铺 + 城门 + 栈桥）
- **店屋外型**：墙身、檐柱+柱础、木构横纵梁、门（斜开门扇+暗门洞+框）、暖光格窗、托臂招牌、布幌+横杆、门前红灯笼、雨搭、飞檐屋面（分段曲面+四角上翘+脊饰吻兽）、茶楼/客栈二层楼（上层窗+平座栏杆）
- **内室**（每店）：地面/四面墙（单面朝内）/天花板/门楣门槛 + 专属陈设（柜台/桌凳/酒瓮/药柜/布匹/床屏风/粮桶/肉案/货架…）+ 卷轴挂画 + 地垫 + 灯笼
- **掌柜位**：每店预留无家具站位（KEEPER_POS，经碰撞核对）

### 3.2 植被
- 垂柳（干 + 低垂叶团 + 垂条）/ 松柏（干 + 锥冠），**InstancedMesh** 实例化

### 3.3 水运
- 汴河（自定义水面着色器：慢波 + 涟漪高光 + 岸边泛白 + 雾）
- 货船 ×3（梭形船体/舷/货舱/桅帆，随波上下浮动）

### 3.4 人物（48 位）
- **身体部件**：躯干/腰带/围裙/头/发髻/帽子（幞头/斗笠/官帽/道冠）/双臂/双手/双腿/双脚
- **动画**：行走摆臂摆腿、躯干起伏、呼吸、面向玩家、漫游巡逻
- **辨识度**：肤色/身高/胖瘦/发型/胡须/帽子/衣色随机组合（组合空间极大）

## 四、音频资产（Web Audio 合成，core/Audio.js）

| 资产 | 音色 | 触发 |
|---|---|---|
| 古风 BGM | 五声音阶拨弦（筝/琵琶式，振荡器+泛音+包络），旋律+低音+点缀 | 进入画卷后循环 |
| 脚步 | 低频短促 | 行走节奏 |
| 对话翻页 | 高频短促 | 打开对话 |
| 铜钱 | 双音 | 购买/奖励 |
| 完成琶音 | 五声上行 | 任务完成 |
| 交互 | 方波短促 | 按钮/失败 |

## 五、体积与性能

- **构建产物**：~620KB（gzip ~167KB），单 JS + index.html，零外链
- **帧预算**：可见三角面 ~10.6 万；draw call ~812（出生街景）
- **内存**：Canvas 贴图均为运行时生成，随用随有
