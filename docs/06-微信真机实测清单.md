## 已知注意

- 微信对 **`requestPointerLock` 支持不稳**：手机端本就走触屏模式不受影响；
  若 Android 桌面版微信有鼠标，视角可用鼠标拖动（无需锁定）。
- 若 BGM 首音延迟：微信偶发要求"二次手势"——再点任意处即恢复（已做兜底）。
- **og:image 需等 GitHub Pages 重新部署完成**，缩略图才会刷新；微信对缩略图有
  强缓存，验证时可给 URL 加 `?v=2` 或换聊天窗口。
- 微信 JS-SDK 自定义分享（标题/图完全可控）需公众号 appid，暂未接入；
  当前用标准 `og:` 标签，绝大多数情况可显示标题+描述+缩略图。

## 若发现问题的快速定位

- 打开 `https://juicyzhou.github.io/qingming-shanghe-tu-3d/?debug=1`：出现「射线」按钮，
  点按可检测屏幕中心命中物体（排查灰蓝平面等）。
- `?simple=1` 关描边 / `?day=1` 恢复正午光照 / `?nocomposer=1` 绕过后处理——用来二分定位画面问题。
